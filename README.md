## 📖 简介

**InfoShield** 是一款专为企事业单位、科研机构及个人隐私合规设计的**现代化轻量离线桌面脱敏工具**。基于 Python 3 与 PySide6 (Qt6) 架构开发，致力于解决在向上汇报、跨部门协作、外部交流、公开演示或向云端 AI 大语言模型（LLM）提交文档前所面临的数据隐私与商业机密泄漏痛点。

针对传统正则替换“误伤排版序号”、“脱敏后文档失真变形”、“云端工具存在二次泄露风险”等顽疾，InfoShield 实现了：
1. **绝不联网的纯离线处理机制**；
2. **科学的字符映射规范（实体上限 3 个符号，数值上限 2 个符号）**；
3. **创新的段落大纲与层级序号严密保护引擎**；
4. **对主流办公文档（Word、Excel、TXT、CSV、Markdown、JSON、XML 等）的原生解析与结构保持**。

## ✨ 核心特性

### 1. 🛡️ 纯离线运行，安全合规
- **零网络访问**：底层没有任何 HTTP/Socket 网络通信代码，不调用任何云端 API，无任何第三方埋点统计与遥测（Zero Telemetry）。
- **物理隔绝环境可用**：可在涉密计算机、内网工作站、离线机房环境直接部署运行。

### 2. 📏 严苛规范的脱敏映射（Length Capping）
- **实体类（单位、行业、姓名、身份证、电话、邮箱等）**：
  - 按字符长度等比例替换为遮蔽符号（默认为 `×`，支持自定义），**上限截断为 3 个符号**。
  - *1 字符 = `×`*，*2 字符 = `××`*，*3 字符及以上 = `×××`*。
  - 既能有效掩盖敏感信息长短特征，又避免过多 `×` 导致版面失真。
- **数据类（金额、数量、占比、百分比、纯数值等）**：
  - 按数值位数等比例替换，**上限截断为 2 个符号 `××`**。
  - *1 位数 = `×`*，*2 位及以上位数/百分比/金额 = `××`*。
  - **智能保留单位与量词**（如 `%`、`‰`、`万元`、`元`、`人`、`户`、`家`、`项`、`台` 等），保留业务语义上下文。

### 3. 📑 独创大纲序号与编号排版严密保护
- 在脱敏前自动建立多级标题、条款大纲、序列标号的特征索引并临时占位隔离，脱敏后精确还原：
  - **中文层级序号**：如 `第一章`、`第1条`、`第二节`、`一、`、`（一）`、`(一)`、`【一】`、`[一]` 等；
  - **阿拉伯多级/单级标号**：如 `1.`、`1、`、`1.1`、`1.1.2`、`(1)`、`（1）` 等（智能区分标题编号与数学小数，杜绝误伤）；
  - **特殊圈号与字母标号**：如 `①`、`②`、`A.`、`(a)`、`I.`、`II.` 等；
- 保障文档的层级架构、目录逻辑与排版美观度完好如初。

### 4. 🗂️ 多格式文档批量无损处理
- 覆盖日常办公与数据交换主流格式（`.docx`、`.xlsx`、`.txt`、`.csv`、`.md`、`.json`、`.xml`）。
- **Word (`.docx`)**：深度解析正文段落与表格（Table）单元格，保留排版样式。
- **Excel (`.xlsx`)**：逐 Sheet 扫描脱敏所有单元格，保持行列结构与工作簿架构。
- **文件与文件夹拖拽**：支持文件、多选及整目录直接拖入。
- **安全防覆盖命名**：处理后的新文件自动保存在**源文件同级目录**，默认追加 `_脱敏` 后缀（如 `季度汇报_脱敏.docx`），若存在同名文件自动按序号递增 `_脱敏(1)`，绝不覆盖篡改原始文件。

### 5. 🎛️ 细粒度控制面板与自定义词库
- **细分子项独立开关**：支持自由开关姓名、企业单位、行业分类、身份证、手机固话、电子邮箱、货币金额、百分比、人数统计、日期年份、独立纯数字。
- **专有词库录入**：支持自定义输入单位库、姓名库、行业词库。
- **白名单豁免机制**：支持设定特定专业术语、公用规范、品牌名称（严禁脱敏，优先级最高）。
- **词库导入与导出**：支持标准 JSON 格式导入导出，便于团队共享与预设复用；内置开箱即用的“示例词库”。

### 6. 🔍 实时对照预览与多维统计看板
- 提供内置的双栏实时对照预览器：左侧原文输入，右侧毫秒级即时呈现脱敏效果。
- 动态输出四大维度精准统计：**已保护序号数**、**实体脱敏处**、**数据脱敏处**、**累计遮蔽处**。

### 7. 🌐 中英双语无缝动态切换 (i18n)
- 界面右上角内置原生多语言切换器（`简体中文` / `English`），无需重启程序，一秒原地热切换所有功能标签、提示文案、规则说明与弹窗。

## 📁 支持的文档格式

| 扩展名 | 格式描述 | 脱敏处理深度 |
| :--- | :--- | :--- |

## 🚀 快速开始

### 环境准备
- 操作系统：Windows 10 / 11、macOS 或 Linux
- Python 环境：Python 3.8 或更高版本

### 方式一：Windows 一键快速启动（推荐）
在项目根目录下，双击运行 **`run.bat`** 即可：
- 自动检测本地 Python 环境；
- 自动校验并补充安装缺失的依赖库（`PySide6`, `python-docx`, `openpyxl`）；
- 无黑框静默启动应用程序。

### 方式二：命令行手动启动
```bash
# 1. 克隆代码仓库
git clone https://github.com/TheBitGlow/InfoShield.git
cd InfoShield

# 2. 安装依赖
python -m pip install -r requirements.txt

# 3. 运行应用程序
python main.py
```

## 🔒 安全与隐私承诺

在数字化协作与大模型落地时代，敏感数据安全是生命线：

1. **绝对离线（100% Offline）**：InfoShield 绝不包含任何外联功能，任何文件均在您本地电脑内存中流转，处理完毕即释放。
2. **源码透明（Open Source & Transparent）**：所有代码纯 Python 开源呈现，无二进制混淆，支持安全团队与审计人员进行任何形式的代码审计。
3. **零数据留存**：程序不设中心化数据库，不保留脱敏历史记录，源文件与脱敏文件均完全由用户本地掌控。

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: 为什么脱敏后的人名或公司名只显示 3 个 ×，而不是按实际字数一一对应？</b></summary>
这是经过深思熟虑的安全设计（Capping 机制）。如果严格按原字数替换（如 4 个字的单位替换为 4 个 ×，2 个字替换为 2 个 ×），攻击者或旁观者依然能根据字长特征进行推测还原。上限截断为 3 个 × 既能破坏长度特征，又能保持版面整齐美观。
</details>

<details>
<summary><b>Q2: 大纲标题里的数字（如 1.1、第一条）会被当成数值误伤脱敏吗？</b></summary>
不会。InfoShield 内置序号保护引擎，在脱敏执行前会优先匹配中文大纲（第一章、一、等）、阿拉伯多级标号（1.1、1.1.2等）以及特殊圈号（①、②等），建立保护占位符并在脱敏完成后精准还原，确保标题序列完好无损。
</details>

<details>
<summary><b>Q3: 脱敏处理后，原始文件会被覆盖吗？</b></summary>
绝不会。InfoShield 默认采用非破坏性另存模式，在源文件同目录下生成带有 `_脱敏` 标记的新文件。即使该目录下已存在同名脱敏文件，也会自动按 `_脱敏(1)` 顺延命名。
</details>

<details>
<summary><b>Q4: 处理超大 Word 或 Excel 文件时界面会卡死吗？</b></summary>
不会。文件批量处理流程运行在独立的后台后台工作线程（`QThread`）中，界面实时响应拖拽与点击，并通过平滑进度条实时展示任务进展。
</details>
