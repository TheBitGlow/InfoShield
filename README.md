# InfoShield - 离线轻量化脱敏工具

一款离线轻量化敏感信息脱敏桌面工具，基于 Python 3 与 PySide6 开发，专为保障数据安全与隐私合规而设计。

---

## 核心特性

1. **纯离线运行，安全无忧**：
   - 绝不联网、无需任何云端 API、无数据上传风险，彻底避免数据泄露。
2. **严格脱敏映射规范**：
   - **实体脱敏（单位、行业、姓名、身份证、电话等）**：按字符数量替换为 `×` 符号，**最长不超过 3 个 `×`**（1字=`×`，2字=`××`，3字及以上=`×××`）。
   - **数据脱敏（金额、人数、占比、百分比、数值等）**：按规则替换为 `×` 符号，**最长不超过 2 个 `××`**（1位数字=`×`，2位及以上数字/百分比=`××`，并智能保留单位如 `%`、`万元`、`人` 等）。
3. **序号与编号严密保护机制**：
   - 全面保护中英文各层级标题、大纲与列表编号：
     - 中文序号：如 `一、`、`（一）`、`(一)`、`【一】`、`第一章`、`第1条` 等；
     - 西文/阿拉伯数字序号：如 `1.`、`1、`、`1.1`、`1.1.2`、`(1)`、`（1）`、`①`、`A.` 等；
   - 序号结构完整保留，绝不误伤，确保文档格式与逻辑层次依然工整。
4. **中英文双语无缝切换（i18n）**：
   - 界面右上角内置原生多语言切换器（`简体中文` / `English`），无需重启程序，一秒原地切换全界面文字、大纲规范、提示与操作弹窗。
5. **多格式文档解析**：
   - 支持 `.txt`、`.docx`（Word 段落、表格完整保持）、`.xlsx`（Excel 工作簿单元格）、`.csv`、`.md`、`.json`。
   - 替换后新文件自动保存在**源文件同级目录**，文件名默认追加 `_脱敏` 标记。
6. **简约时尚的图形界面**：
   - 窗口标题统一标为：**`InfoShield`**。
   - 支持**文件/文件夹拖拽直接投放**与多选批量处理。
   - 提供**细分子项独立控制面板**与**实时对照预览框**，脱敏前 vs 脱敏后一览无余，并提供精准脱敏统计指标。
   - 支持自定义单位名、人员姓名、行业词库与白名单豁免词。

## 快速运行

### 方式一：双击快捷运行（Windows）
在根目录下双击 `run.bat` 即可一键启动。

### 方式二：命令行运行
```bash
# 1. 安装依赖（如果尚未安装）
python -m pip install -r requirements.txt

# 2. 启动应用程序
python main.py
```
